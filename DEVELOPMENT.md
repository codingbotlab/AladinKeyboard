# Private development repository

This repository is private. Do not change it to public or copy its source files to the public binary-only distribution repository.

The project builds with Android SDK 35 and Java 17. `local.properties` is intentionally excluded because it contains machine-specific SDK paths. Release signing keys and generated APKs are intentionally excluded; keep the signing keystore and its password backed up securely and never commit them.

The public download listing is maintained separately at https://github.com/codingbotlab/AladinKeyboard-Android.
