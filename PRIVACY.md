# Aladin Keyboard — Beta Privacy Notice

This beta stores keyboard learning data locally on the Android device. Cloud sync is off by default and requires explicit opt-in. When enabled, the app uses HTTPS to sync learned word-frequency entries and word-pair entries to/from the Aladin Supabase project, scoped by Supabase row-level security to a per-install anonymous account. These entries may contain individual words the user typed, but the app does not intentionally upload raw keystroke events, full typed sentences, or passwords. Anonymous accounts are not recoverable on another device unless account linking/sign-in is added later. Supabase Auth must have Anonymous Sign-Ins enabled for this feature to work.

If the user explicitly enables PC sync, the app sends learned word-frequency counts, learned word-pair counts, and a device identifier to the configured PC on the local network. The PC sync transport is plain HTTP and should only be used on a trusted private Wi-Fi network. Voice typing invokes the device's Android speech-recognition provider; its processing and network behavior are controlled by that provider and device settings. The app requests microphone access for voice typing and network access for sync features.

This notice describes the current beta implementation and is not a substitute for a full store-compliance review. Do not use this beta for sensitive typing until the privacy and sync behavior has been independently reviewed.
